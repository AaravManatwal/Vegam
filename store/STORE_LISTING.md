**App name (max 30):** Vegam: Download Manager

**Category:** Tools
**Tags/keywords:** download manager, fast download, resume download, file downloader

## Full description (English)
Vegam is a fast, clean download manager for Android.

- Faster downloads: one file is split into up to 16 parts and downloaded at the same time.
- Never start over: if the network drops or the app closes, downloads resume where they stopped.
- Queue and schedule: set how many downloads run together, start later (for example at 2 AM), or Wi-Fi only.
- Speed limit: keep some bandwidth free for other apps.
- Live details: per-part progress, a 60-second speed graph and SHA-256 check for finished files.
- Share a link from your browser straight into Vegam.
- Your folder: save to app storage or any folder you choose.
- Private: no account, no ads, no analytics.
